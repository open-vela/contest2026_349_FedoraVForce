# aircon（空调）

从桌面启动，通过 `app/mihome` 读写空调伴侣，2 秒刷新一次：

- 设定温度（大字，− / + 按钮，16–30°C，开机时可用），模式，压缩机状态
- 当前功率和最近 2 分钟的曲线
- 大按钮开关，开着时整页变蓝

空调伴侣只记得自己用红外发过什么，`power` 不代表空调真的在制冷，压缩机
状态按实测功率判断：低于 60 W 显示 WAITING（压缩机保护或室温已经够低）。

网络在应用自己的线程里，每 2 秒一次，按按钮后立即一次，每条命令后都读回
状态。顶部状态：`NOT CONFIGURED`（配置文件有问题，或在 `miio mode real`
下没有配置文件）、`OFFLINE`（设备不回）、`ONLINE`；用 mock 时显示
`MOCK DEVICE` 和「演示模式 · 模拟设备」标签，真设备和 mock 之间切换时
功率曲线清空。
